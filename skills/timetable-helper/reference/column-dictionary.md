Column Dictionary

This file explains each column in timetable.csv

day

The day of the week the class is held.
Possible values: Monday, Tuesday, Wednesday, Thursday, Friday
Never includes Saturday or Sunday.

time

The time slot of the class in 24-hour format.
Format is HH:MM-HH:MM
Example: 09:00-10:00 means the class starts at 9am and ends at 10am

subject

The name of the subject being taught.
Current subjects in the timetable:

Mathematics
Physics
English
Computer Networks
Data Structures

If a student asks about a subject not in this list, respond with “Not found in timetable”. Do not invent a subject.
