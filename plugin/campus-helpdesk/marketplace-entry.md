Description

The campus-helpdesk plugin helps students get instant answers about their class timetable, fee status and hostel rules. It bundles the timetable-helper Skill, a slash command, a file protection hook and a live MCP server connection into one installable unit.

What This Plugin Does
Answers timetable queries using the timetable-helper Skill
Provides a /timetable slash command for quick lookups
Blocks accidental writes to protected student data folders
Connects to the campus MCP server for live fee and hostel data
Requirements
Python 3.9 or above
MCP server running locally
